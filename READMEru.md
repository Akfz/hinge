# Hinge Launcher

Кроссплатформенный (Linux, Windows) лаунчер Minecraft на C++20 с локальным
веб-интерфейсом.

Лаунчер запускает HTTP-сервер на localhost и открывает UI в браузере —
ничего дополнительно устанавливать не нужно, а весь интерфейс написан на
голом HTML/CSS/JS и вшит в бинарник.

## Возможности

- **Официальная Microsoft-авторизация** — без прокси и переиспользования
  чужих client ID. Резервный client ID — на случай недоступности основного.
- **Ванилла и модлоадеры** — Fabric, Quilt, Forge, NeoForge. Установка
  в один клик, прогресс по фазам, сырой вывод инсталлятора в консоль.
- **Портативные Java** — лаунчер сам скачивает нужную версию JDK
  (Adoptium Temurin) и подкладывает её при запуске. Автоопределение
  требуемой версии по версии Minecraft.
- **Профили** — офлайн и Microsoft, несколько `.minecraft` каталогов на
  профиль, отдельный объём RAM и путь к Java для каждого.
- **Встроенная консоль** — логи установки, инсталляторов и самого
  Minecraft в реальном времени, с фильтрами по уровню (INFO / WARN / ERROR).
- **UI без сборки** — весь фронт (HTML/CSS/JS) вшит в `DefaultWeb.h`
  как raw string literals и распаковывается в `web/` при первом запуске.
  Нет npm, webpack, node_modules.

## Требования

- CMake 3.16+
- Компилятор с поддержкой C++20 (GCC 11+, Clang 14+, MSVC 19.30+)
- OpenSSL (dev-пакет)

`httplib` и `nlohmann/json` подтягиваются автоматически через `FetchContent`.

## Запуск

Сервер на `localhost:12345`, UI откроется в браузере. Порт меняется
в настройках или через `-1` (случайный свободный).

Данные рядом с бинарником: `config.json`, `profiles/`, `runtimes/`, `web/`.

## Редактирование UI

Файлы в `web/` читаются с диска при каждом запросе — правь HTML, CSS
или JS, сохраняй, вкладка перезагрузится сама. Если удалить файл, он
восстановится из вшитой копии при следующем запуске. Существующие
файлы не перезаписываются.
